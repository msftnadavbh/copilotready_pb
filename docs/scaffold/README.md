# Reusable Copilot context templates

These are generic templates, not an installer. Review and adapt them before placing them in an existing profile or project. The setup wizard does not silently overwrite your repository with this scaffold.

The profile contains conservative defaults and a reusable verification skill. The project contains instructions, an explicitly referenced memory note, and one path-specific rule. Replace placeholder project commands with verified commands from your own repository.

Native persistent memory is separate from MEMORY.md. Hooks, MCP connections, credentials, models from other products, and schedules are not activated by these templates.
